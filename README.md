# 知微 · 游戏策划 AI 知识工作台

> 一个 DSH 插件：把策划的设计结论、规则、假设、问题、方案、参考、数值和复盘，整理成**有类型、有状态、有来源、有语义关系**的记忆，用主题集合自动归纳，用三栏工作台和可探索的知识图谱随时找回来。

之前的名字是「策划记忆」（1.x）。2.0.0 起叫**知微**，内部包名与数据目录保持不变，旧数据自动迁移。

## 它解决什么问题

策划的知识散在聊天、文档、表格和脑子里。三个月后你会遇到这些情况：这条数值还生效吗？当时为什么这么定？改这个会不会影响别的系统？新方案和旧方案是冲突还是替代？

知微给每条知识一个结构化外壳，并让 AI 负责整理、你负责确认：

- **类型**回答「这条是什么」：设计决策 / 设计规则 / 设计假设 / 设计问题 / 设计方案 / 参考案例 / 数值数据 / 复盘结论 / 流程约定。
- **领域**回答「属于哪块业务」：战斗、成长、经济、关卡、活动、UI/UX、商业化、社交、运营、技术约束，可多选。
- **状态**回答「能不能用」：草稿 / 待确认 / 已生效 / 已废弃 / 已归档。
- **来源**回答「从哪来」：手动 / 对话 / 导入 / AI 整理。
- **关系**回答「和谁有关」：归属于 / 依赖于 / 影响 / 来源于 / 参考 / 冲突 / 替代 / 细化，有方向、有确认状态。

## 功能

**三栏知识工作台**：左导航（项目空间、全部记忆、待整理、主题集合、收藏、最近访问、关系图、保存的视图）、中内容区（搜索、筛选、列表/卡片、概览）、右详情栏（类型状态、来源、正文、领域、集合、按类型分组的关系、AI 辅助、改动记录）。两栏可折叠，窄屏自适应。

**快速新增**：粘贴一段原文，自动得到标题、摘要、类型、领域、标签、原子化拆分建议与相关集合；一键应用或直接保存。AI 整理过的内容默认落在「待确认」。

**记忆列表**：搜索 + 项目/类型/领域/状态/标签联合筛选，列表或卡片，按更新时间/创建时间/标题排序，多选批量操作（加入集合、改状态、删除）。

**主题集合**：手动创建、批量加成员、移出、改名改简介、合并、拆分；AI 聚类建议带名称、简介与归类理由；集合页一键生成主题总结。

**关系图**：分簇自动布局、节点拖拽（只改显示，不改数据）、集合边界与折叠、按类型/关系/领域/集合筛选、搜索定位、点击开详情、按关系类型区分线型与箭头、框选批量操作、保存视图、深浅色适配。

**AI 辅助**（本地启发式，全部附理由）：整理这条、找相似、推荐关联、查冲突、上下游分析、主题总结。AI 只给建议，不会自动把假设升格成规则，也不会擅自覆盖旧数据。

**操作反馈**：统一 toast、进行中/完成态、删除二次确认、空状态引导、错误文案；删除记忆或集合后在 toast 里可撤销，连同关系与集合归属一起恢复。

## 安装

```bash
dsh plugin add github:ivezhang/dsh-GameDesignMemory
```

或把仓库克隆到插件目录，在 `cordis.patch.yml` 里插入：

```yaml
- insert:
    - id: design-memory
      name: '@local/design-memory'
```

安装后重启 DSH，左侧栏出现「知微」。

## 用起来

1. **记录**：点左上「新建记忆」，把脑子里那段话直接粘进去 →「AI 整理」看建议 →「保存」。不想被整理就「只保存」。
2. **确认**：在「待整理」里把草稿改成待确认/已生效；确认过的规则才是规则。
3. **归类**：到「主题集合」让 AI 提聚类建议，接受有用的，改名改简介，把不合适的移出去。
4. **探索**：打开「关系图」，按领域/类型筛选，点节点看详情；用「划线」建立语义关系；框选一组记忆直接建集合；把当前视图保存下来下次一键回来。
5. **和 AI 一起用**：在对话里让智能体用 `design_memory_search` / `design_memory_write` / `design_memory_suggest` / `design_memory_analyze` 帮你检索、整理与归纳。

## 数据与备份

- 位置：`%DSH_HOME%/design-memory/memories.json`（默认 `C:\Users\<你>\.dsh\design-memory\`），当前版本 3。
- 每次写入前保留 `memories.json.bak`；写入用临时文件 + 原子改名；坏文件改名 `.corrupt-<时间戳>`，不静默丢数据。
- 备份就是复制整个目录。

## 目录结构

```
index.js            host：存储、迁移、分析引擎、三个 AI 工具、HTTP 接口
client.js           前端：三栏工作台、列表、详情、编辑器、关系图、AI 面板
cordis.patch.yml    插件挂载补丁
locale/             插件元信息（中文 / 英文）
docs/DETAIL.md      详细说明：数据模型、关系、集合、AI 规则
docs/CHANGELOG.md   更新记录
docs/UPGRADE-2.0.0.md  从 1.x 升级的注意事项
tests/              行为测试、渲染冒烟、迁移校验、静态一致性审计
```

## 测试

```bash
node tests/host-test.mjs       # host 行为（迁移、CRUD、关系、集合、建议、撤销）
node tests/render-smoke.mjs    # 前端渲染与交互冒烟
node tests/migrate-live.mjs    # 真实数据结构迁移校验
node tests/static-audit.mjs    # i18n 与样式类名一致性
```

## 兼容性与限制

- 无第三方运行时依赖，无构建步骤；host 是 Node ESM，前端是浏览器模块（只依赖 `react`）。
- 支持浅色/深色主题，跟随 DSH。
- 分析引擎是规则化启发式，不是大模型：不做语义向量检索，不做自动写入。
- 单机数据，暂无多用户协作与云同步。
