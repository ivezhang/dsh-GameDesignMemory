# 策划记忆（Design Memory）

> 给游戏策划用的 DSH 长期记忆插件：把已经确认的**系统规则**、**数值口径**和**流程约定**留在左侧栏，换会话、隔几周再回来，人和 AI 都能直接查到。

这是 DeepSeek Harness（DSH）的一个插件。它在左侧栏新增「策划记忆」面板，同时向 Agent 注册两个工具，面板与 AI 读写同一份本地 JSON。没有外部服务，没有网络请求。

当前版本 **v1.3.0**。

## 它解决什么

策划的结论常常散在聊天记录、表格批注和文档评论里：一个概率上周调过、一个货币产出口径上个月改过、某个系统的边界条件只在一句话里说过。等下次要改同一个系统时，翻记录的成本比重新想一遍还高。

这个插件把这些结论变成可检索的条目：分类、状态、关键要点、来源和改动记录都在一处，AI 在动手改数值之前也能先查到历史结论。

## 功能

- **四类记忆**：系统 / 数值 / 工作流 / 其他，可按状态（待确认 / 已确认 / 已废弃）筛选。
- **手动确认 / 废弃**：待确认的条目在详情里直接点按钮转状态，不用再猜「待确认」是什么意思；切错可以再切回来，每一步都写进改动记录。
- **结构化条目**：标题、摘要、关键要点（`名称 = 值`）、详细说明、标签、来源、改动记录。
- **关联记忆**：把两条记忆串起来，可写一句关系说明；删除条目会自动清理别人指向它的关联。
- **神经网络式关系网**：记忆是神经元，关联是突触，记忆区是有颜色的光晕；带光点脉冲的信号流动效果，可拖拽、滚轮缩放、拖空白平移。单击节点在侧边抽屉里单独查看，支持「只看这一条」「重新排版」和按共同标签生成的临时虚线。
- **划线建立关联**：关系网上把工具切到「划线」，从一个节点拖到另一个节点就建立关联，不用回详情页；按住 `Shift` 拖节点也能临时划线。
- **画框圈记忆区**：切到「圈区」，在空白处拖一个框，框里的记忆就被圈成一个带名字和颜色的记忆区；右上角记忆区面板可聚焦、改名、换色、删除，一条记忆最多属于一个区。
- **深色主题**：跟随 DSH 的浅色 / 深色主题自动切换，关系网的网格、连线、节点环都有对应深色值。
- **全文搜索**：标题、摘要、正文、标签和要点一起匹配，输入即筛。
- **置顶**：反复要用的口径固定在列表顶部。
- **Agent 读写**：直接说「把这条记到数值记忆里」「查一下战令奖励之前定过多少」，AI 通过工具读写同一个库，面板刷新即可看到。

## 安装

### 通过 DSH 插件页（推荐）

1. 打开 DSH 的 **插件** 页。
2. 点 **Add plugin**，在包名 / 地址框填入仓库地址：

   ```text
   https://github.com/ivezhang/dsh-GameDesignMemory
   ```

3. 点 **Install**，按提示确认。

如果本机装有 DSH 命令行工具，也可以用（具体子命令以 `dsh plugin add --help` 为准）：

```bash
dsh plugin add github:ivezhang/dsh-GameDesignMemory
```

### 本地目录（开发调试）

```bash
git clone https://github.com/ivezhang/dsh-GameDesignMemory.git
```

然后在 **插件 → Add plugin** 中填入仓库的绝对路径。本地目录方式会链接该目录，改完代码重新加载即可，不必反复打包。

安装完成后，左侧栏会出现「策划记忆」入口；新开一个会话，AI 就能使用这两个工具。

## 使用

### 面板

1. 左侧栏点击 **策划记忆**。
2. 左列选分类（全部 / 系统 / 数值 / 工作流 / 其他），下方按状态筛选。
3. 中点列表选条目，右侧看详情或进入编辑。
4. **新建记忆** 填写标题、分类和内容；关键要点每行一条 `名称 = 值`。
5. 右上角切换到 **关系网** 看全局结构，可以直接在图上划线建立关联、拖框圈记忆区。

每条记忆的「改动记录」会留下每次编辑的时间和说明，方便回溯「这个数什么时候改的、为什么改」。

### 状态怎么用

| 状态 | 什么时候用 | 详情里能点的按钮 |
|---|---|---|
| 待确认 | 结论还要复核，先记下来 | 确认 / 废弃 |
| 已确认 | 可以直接拿来做设计 | 废弃 |
| 已废弃 | 老口径，留档但不再用 | 恢复为已确认 |

### 关系网怎么用

- 节点是记忆，连线是关联，节点颜色代表分类；拖动节点摆放位置，拖空白平移，滚轮缩放，工具栏可放大 / 缩小 / 适应窗口。
- 工具栏中间是三个工具：**选择**（默认）、**划线**、**圈区**。
- 单击节点 → 右侧抽屉看完整详情，可以直接编辑或改状态。
- **划线**：从一个节点拖到另一个节点，松手即建立关联；拖的时候有虚线跟着光标，目标节点会高亮。按住 `Shift` 拖节点也能临时划线。
- **圈区**：在空白处拖一个框，框里的记忆圈成一个记忆区；框里没节点时不会建，会提示一下。
- **只看这一条**：只保留选中节点和它的邻居。
- **重新排版**：条目多了之后一键摊开，同一个记忆区的节点会被拉到一起。
- **自动关联**：按共同标签补虚线，只用于看图，不会写进数据。

### 记忆区怎么用

- 关系网右上角会出现 **记忆区** 面板（有区时才显示），列出所有区及成员数量。
- 点一行聚焦这个区，其他节点与连线变淡，再点一次取消。
- 点色块换颜色（六色轮转），点名字直接改名，回车确认 / `Esc` 取消。
- 垃圾桶点两下删除整个区；只删分区，记忆本身还在，区空了也会自动消失。
- 一条记忆最多属于一个区，画进新区会自动从旧区移走。
- 列表视图里，属于某个区的记忆，详情顶部会显示区名标签。
- 也可以直接跟 AI 说「把战令和付费点相关的几条圈成一个区」，AI 通过 `region-save` 建区。

### 和 AI 一起用

```text
把这条记到系统记忆里：体力上限随等级提升，公式是 100 + 等级 × 10。
查一下战令奖励之前定过多少。
把「随机皮肤放大器 = 20」更新成 15，说明写「S3 削减付费点」。
把「战令奖励」和「付费点设计」这两条串起来，说明写「战令是主要付费入口」。
把那条待确认的战令结论确认掉。
```

AI 会调用 `design_memory_search` 先查已有结论，再用 `design_memory_write` 保存、更新、删除、改状态或建立关联。

## 数据与备份

默认保存在：

```text
%DSH_HOME%\design-memory\memories.json
```

通常是 `C:\Users\<你>\.dsh\design-memory\memories.json`，面板左下角也会显示实际路径。

- 每次写入前，上一版会复制为 `memories.json.bak`。
- 文件读不出来时，会改名为 `memories.json.corrupt-<时间戳>` 保留现场，不会静默覆盖。
- v1.3.0 起文件里多了 `regions`（记忆区），`version` 为 `2`。
- 从 v1.2.0 及更早版本升级无需迁移：缺少的 `links` / `regions` 字段自动补空数组，悬空关联、不存在的区成员自动清理。
- 删除条目不可恢复，删前请自行备份。

> 记忆库只在本机，不做多端同步。换机器时手动复制 `memories.json` 即可。

## 兼容性与限制

- 需要带 Web 客户端和 `tools` 服务的 DSH 版本；当前 DSH Desktop 可直接使用。
- 无第三方依赖、无构建步骤，Host 与 Client 都是原生 ESM / 浏览器模块。
- 单机单库；面向个人策划工作集（数百条量级），未做分页和索引。
- 记忆区是单层分区：一条记忆只属于一个区，不支持区里再套区或子图折叠。
- 面板较窄时三栏会自动收窄，信息以列表和详情为主；关系网在宽面板下体验最好。

## 更新记录

### v1.3.0

- 关系网整体重做，视觉改成「神经网络」：节点是带光晕与呼吸动画的神经元，关联是二次贝塞尔突触，边上叠了沿路径流动的信号脉冲，画布有暗角光晕与点阵底纹（浅色 / 深色各一套配色）。
- 新增 **划线关联**：工具栏切到「划线」，节点拖到节点即建立关联；`Shift` + 拖节点也能临时划线，靠近目标时节点会高亮，失败时（拖到空白、自己连自己）有瞬时提示。
- 新增 **记忆区**：切到「圈区」，在空白处拖框把一堆记忆圈成一个区，渲染为带颜色的凸包光晕；记忆区面板支持聚焦、改名、换色、双击删除，列表详情顶部显示区名标签。
- 记忆区是互斥分区：一条记忆最多属于一个区，画进新区会自动从旧区移走。
- 布局升级为聚类力导向：同一个区的节点互相吸引，重新排版后按区聚拢。
- 数据升级到 `version: 2`，新增 `regions`；旧数据直接可读，悬空关联与不存在的区成员自动清理。
- 工具扩展：`design_memory_write` 新增 `region-save` / `region-delete` 与 `regionId`、`name`、`color`、`memberIds` 参数；`design_memory_search` 与列表输出会带上所属记忆区。
- 深色主题补齐新图元（光晕、脉冲、区色）的对应色值。

### v1.2.0

- 新增 **关系网视图**：力导向布局，节点可拖拽、画布可平移、滚轮缩放，单击节点在抽屉里单独查看；支持只看一条、重新排版、按共同标签生成只读虚线。
- 新增 **关联记忆**：条目之间可建立带说明的关联，详情里可添加 / 移除，列表行显示关联数，删除条目级联清理。
- 新增 **手动确认 / 废弃**：「待确认」不再是含义模糊的标签，详情里直接给说明和按钮，并写入改动记录。
- 新增 **深色主题**：自带 `--dm-*` 语义色层，跟随 DSH 主题切换，关系网与阴影均有深色值。
- 工具扩展：`design_memory_write` 新增 `status` / `link` / `unlink` 动作与 `targetId`、`links` 参数；搜索结果补上「关联 / 被关联」。
- 兼容旧数据：自动补齐 `links` 字段并清理悬空关联。

### v1.1.0

- 新增「工作流」分类。

### v1.0.0

- 首个版本：分类 / 状态 / 要点 / 标签 / 来源 / 改动记录，全文搜索、置顶、Agent 读写。
