# 策划记忆

左侧栏的长期记忆库，专门给策划用：把已经确认的**系统规则**、**数值口径**和**其他约定**存下来，下次开新会话时人和 AI 都能直接查到，不用再翻聊天记录。

## 位置

- 左侧栏点击 **策划记忆**（三点/记忆卡片图标）进入。
- 面板左侧是分类：**全部 / 系统 / 数值 / 其他**，可再按状态筛选（待确认 / 已确认 / 已废弃）。
- 中间是列表，右侧是详情或编辑器。

## 每条记忆包含

| 字段 | 用途 |
|---|---|
| 分类 | 系统 / 数值 / 其他 |
| 标题 | 一句话说明这条记忆是什么 |
| 摘要 | 解决什么问题，列表里直接可见 |
| 关键要点 | 「名称 = 值」的键值对，最适合放数值、阈值、表名 |
| 详细说明 | 规则、口径、代码位置、结论；支持 `-` 列表与 `###` 小标题 |
| 标签 | 逗号分隔，便于搜索 |
| 状态 | 待确认 / 已确认 / 已废弃 |
| 来源 | 这条结论来自哪次会话、哪个文档或哪张表 |
| 改动记录 | 每次编辑留下时间与改动说明 |

## AI 读写

插件向 Agent 注册了两个工具：

- `design_memory_search`：先查已有结论，再动手改系统或数值；给 `id` 可读全文。
- `design_memory_write`：`save` / `update` / `delete`，把用户确认过的新结论写回来。

因此可以直接说「把这条记到数值记忆里」「查一下战令奖励之前定过多少」，AI 会读写同一个库，面板刷新后即可看到。

## 存储

数据保存在本机 DSH 目录下：

```text
%DSH_HOME%\design-memory\memories.json
```

默认是 `C:\Users\<你>\.dsh\design-memory\memories.json`，纯 JSON、可直接备份或复制到别的机器。面板左下角也会显示实际路径。

## 限制

- 单机单库，不做多端同步；换机器需要自己拷 `memories.json`。
- 删除不可恢复（请在删除前自行备份）。
- 改动记录只保留时间与说明，不保留旧正文快照。
