# 策划记忆

左侧栏的长期记忆库，专门给策划用：把已经确认的**系统规则**、**数值口径**、**常用工作流**和**其他设计约定**存下来，下次开新会话时人和 AI 都能直接查到，不用再翻聊天记录。

## 位置

- 左侧栏点击 **策划记忆**（三点/记忆卡片图标）进入。
- 面板左侧是分类：**全部 / 系统 / 数值 / 工作流 / 其他**，可再按状态筛选（待确认 / 已确认 / 已废弃）。
- 中间是列表，右侧是详情或编辑器。
- 面板右上角可以在 **列表** 和 **关系网** 两个视图之间切换。

## 每条记忆包含

| 字段 | 用途 |
|---|---|
| 分类 | 系统 / 数值 / 工作流 / 其他 |
| 标题 | 一句话说明这条记忆是什么 |
| 摘要 | 解决什么问题，列表里直接可见 |
| 关键要点 | 「名称 = 值」的键值对，最适合放数值、阈值、表名 |
| 详细说明 | 规则、口径、代码位置、结论；支持 `-` 列表与 `###` 小标题 |
| 标签 | 逗号分隔，便于搜索 |
| 状态 | 待确认 / 已确认 / 已废弃 |
| 关联记忆 | 连到别的条目，并可写一句关系说明 |
| 来源 | 这条结论来自哪次会话、哪个文档或哪张表 |
| 改动记录 | 每次编辑留下时间与改动说明 |

## 状态与手动确认

三种状态的意思：

- **待确认**：结论还需要你或别人复核，先记下来别丢。这类条目在详情里会显示一行说明和两个按钮。
- **已确认**：这条口径可以直接拿来用，AI 也会把它当既定结论。
- **已废弃**：旧结论，留档备查但不再适用。列表里会变淡，检索时仍然能找到。

详情里的操作：

| 当前状态 | 可以点的按钮 |
|---|---|
| 待确认 | **确认**（转为已确认）、**废弃**（转为已废弃） |
| 已确认 | **废弃** |
| 已废弃 | **恢复为已确认**（误废弃时用） |

每次切换都会写进「改动记录」，说明为「确认了这条记忆 / 废弃了这条记忆 / 重新打开待确认」。状态也可以让 AI 改：`design_memory_write` 的 `status` 动作。

## 关联与关系网

### 建立关联

两种方式，写进去的是同一条数据：

- **在详情页**：**关联记忆** 区域选一条目标记忆、可选填一句关系说明，点 **添加关联**。
- **在关系网上直接划线**：工具切到 **划线**，从一个节点拖到另一个节点，松手即连上；按住 `Shift` 拖节点也能临时划线。拖动时会拉出一条指向光标的虚线，光标下的目标节点会高亮。

同一目标重复添加只会更新说明，不会重复连线；删除条目时会自动清掉别人指向它的关联。

### 关系网视图

点面板右上角的 **关系网**：节点是记忆，连线是关联，节点颜色代表分类。

- **拖拽**：拖动任意节点调整位置，拖空白处平移整张图。
- **缩放**：滚轮以光标为中心放大缩小（0.15×–3×），也可以用工具栏的 放大 / 缩小 / 适应窗口。
- **三个工具**（工具栏中间）：
  - **选择**：默认状态，拖节点、点节点看详情。
  - **划线**：从节点拖到节点，直接建立关联。
  - **圈区**：在空白处拖一个框，把框里的记忆圈成一个 **记忆区**。
- **单独查看**：单击节点，右侧抽屉显示这条记忆的完整详情（可编辑、可确认 / 废弃）；点 **只看这一条** 只保留它和一圈邻居。
- **重新排版**：按记忆区聚类重算布局，同一个区的节点会被拉到一起。
- **自动关联**：按共同标签补虚线（仅显示用，不写进数据），右下角有图例。
- 有连线的条目，列表行右侧会显示关联数徽标。

### 记忆区

记忆区是「一堆有关系的记忆」的容器，在关系网上表现为一圈带颜色的光晕，把区里的节点包起来。

- 工具切到 **圈区**，在空白处拖框，松手即建区；框里没有节点时不会建，会提示一下。
- 每个区有名字和颜色（六色轮转）。名字默认是「记忆区 N」，点名字可直接改名，点色块可换色。
- **一条记忆最多属于一个区**：把它画进新区，会自动从旧区移走。
- 右上角的 **记忆区** 面板列出所有区：点一行聚焦这个区（其他节点变淡，再点一次取消），色块点一下换色，垃圾桶点两下删除整个区。
- 删除区只删分区，记忆本身保留；区里空了以后区会自动消失。
- 列表视图里，属于某个区的记忆，详情顶部会显示一个区名标签。
- AI 也能建区和改区：`design_memory_write` 的 `region-save` / `region-delete`。

## 分类怎么放

- **系统**：玩法规则、模块机制、边界与异常口径。
- **数值**：产出消耗、概率阈值、平衡结论。
- **工作流**：常用工作细节，例如怎么翻译、去哪找竞品、目录与命名约定、交付方式、协作流程。
- **其他**：设计口味、文案与表现等设计约定。

## AI 读写

插件向 Agent 注册了两个工具：

- `design_memory_search`：先查已有结论，再动手改系统或数值；给 `id` 可读全文，输出里会列出关联与被关联。
- `design_memory_write`：
  - `save` / `update` / `delete`：新建、修改、删除条目；
  - `status`：改状态（确认 / 废弃 / 退回待确认）；
  - `link` / `unlink`：建立或解除关联，`targetId` 指定目标；
  - `region-save` / `region-delete`：建区、改区（名称 / 颜色 / 成员）、删区。

因此可以直接说「把这条记到数值记忆里」「查一下战令奖励之前定过多少」「把这两条串起来」「把战令和付费点那几条圈成一个区」，AI 会读写同一个库，面板刷新后即可看到。

## 主题

面板跟随 DSH 的浅色 / 深色主题自动切换：插件只引用主题变量，并额外用一层自己的语义色（`--dm-*`）处理关系网的网格、连线、节点环和阴影，深色下不会出现白底或看不清的浅色块。切换主题不需要重开面板。

## 存储

数据保存在本机 DSH 目录下：

```text
%DSH_HOME%\design-memory\memories.json
```

默认是 `C:\Users\<你>\.dsh\design-memory\memories.json`，纯 JSON、可直接备份或复制到别的机器。面板左下角也会显示实际路径。

- 写入前上一版会复制为 `memories.json.bak`。
- 读取失败时不会静默覆盖，原文件会改名为 `memories.json.corrupt-<时间戳>` 保留现场。
- v1.3.0 起文件里多了 `regions`（记忆区），`version` 为 `2`；v1.2.0 及更早的数据可以直接读，缺的字段自动补空数组，悬空关联与不存在的区成员会被清理。

## 限制

- 单机单库，不做多端同步；换机器需要自己拷 `memories.json`。
- 删除不可恢复（请在删除前自行备份）。
- 改动记录只保留时间与说明，不保留旧正文快照。
- 记忆区是单层分区：一条记忆只属于一个区，不支持区里再套区或子图折叠；条目数量在数百条量级以内体验最佳。
