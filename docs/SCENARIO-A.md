> 由 tests/scenario-a.mjs 在一个临时 DSH_HOME 里从空库搭出来，不接触线上数据。对应 V2.4 需求书第十二节场景 A。

## 搭出来的结构

| 对象 | 类型 | 父级 | 关系 |

| 副本系统 | system | — | contains → 哥布林洞窟 |
| 哥布林洞窟 | concept | 副本系统 | contains → 哥布林 |
