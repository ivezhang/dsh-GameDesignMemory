# 知微 · 上手指南（5 分钟）

> 面向第一次用的人。只讲「怎么用」，不讲原理。完整功能见 [FEATURES.md](FEATURES.md)，逐条需求对照见 [TRACEABILITY.md](TRACEABILITY.md)。

## 一、三栏是什么

| 位置 | 作用 |
| --- | --- |
| 左栏 | 导航（工作台 / 全部记忆 / 待整理 / 整理中心 / 主题集合 / 收藏 / 调用记录 / 知识网络 / 关系图）+ 项目空间 + 保存的视图 |
| 中栏 | 当前导航的内容：列表、卡片，或关系图画布 |
| 右栏 | 选中项的详情：正文、状态、标签、来源证据、版本历史、关联记忆、AI 建议 |

左栏顶部 `+ 新建记忆` 随时可用；左栏底部可以「收起导航」，把空间让给画布。

## 二、第一次使用：三步

1. **建一条记忆**：点 `+ 新建记忆`，写标题与正文，选类型（这是决策？规则？假设？）和领域，状态先放「待确认」。
2. **让 AI 观察一段对话**：顶栏「观察」，把这段聊天里值得留下的结论贴进去，知微会拆成记忆草稿，并顺手建议关系与知识对象。
3. **过一遍整理中心**：左栏「整理中心」里六类卡片——重复记忆、疑似重复对象、未归类、候选对象、缺来源、缺证据。能确认的点「确认 / 全部确认」，剩下的自己补。

写记忆时不用担心「写错了」：每条记忆都有版本，改一次留一版，可以回滚；点右上角历史能看到每次改了哪几个字。

## 三、常用动作

| 想做的事 | 怎么做 |
| --- | --- |
| 找东西 | 顶栏搜索框（`Ctrl / Cmd + K` 直接聚焦），`Enter` 打开第一条；搜索覆盖记忆、知识对象、集合、项目 |
| 加标签 / 批量改状态 | 列表里勾选 → 底部批量条 |
| 删错了 | `Ctrl / Cmd + Z`，或点顶栏环形箭头按钮（最多退 5 步） |
| 这条不能被 AI 改 | 详情里把保护级别调成「固有约定」；AI 只能提矛盾，改不动 |
| 这条属于别的项目 | 详情里改「项目」，或列表批量条里批量移动 |
| 忘了为什么这么定 | 详情里的「来源与证据」「改动记录」「版本历史」 |

## 四、项目空间

项目空间在左栏导航上方，是一个隔离层：不同项目的记忆互不干扰，按项目召回时也不会串味。

- **新建**：项目空间标题栏的 `+`。
- **改名 / 删除**：右键项目行。删除会把里面的一切迁到兜底项目（不会丢东西）。
- **排序**：拖动项目行。
- **多选批量迁移**：点标题栏的「批量选择」→ 勾选要并走的项目 → 选目标项目 → 「迁移并合并」。记忆、知识对象、记忆区、集合、保存的视图一起迁过去，源项目消失。适合清理误建的空项目。
- **导出单个项目**：右键项目行 →「导出这个项目」，得到一个只含该项目的 JSON（含知识对象），可以单独备份或交给别人。

## 五、关系图：怎么连、怎么框、怎么删

关系图是探索工具，不是装饰。

- **连关系**：工具条切到「划线」，从一个节点拖到另一个节点，松手后选关系类型（28 种，按层级 / 业务 / 流程 / 原则 / 知识分组），可以写一句理由。
- **画记忆区**：工具条切到「画框」，在空白处拖出一个矩形，框住的节点自动归属这个记忆区；框还能套框。框可以拖动整块、四角缩放、双击改名。
- **删记忆区**：先点选框（点虚线轮廓或中间的胶囊都行），工具条会出现「删除记忆区」；或者直接按 `Delete`。**只删框，里面的记忆和对象都保留。**
- **摆位置**：拖动节点，工具条点「保存布局」；下次打开还在原位。
- **缩放 / 平移**：滚轮缩放，`Space + 拖动` 或拖空白平移，`Esc` 逐层退出选择。

## 六、知识网络：记忆是点，对象是网

- 知识对象是「系统 / 概念 / 流程 / 偏好 / 原则 / 项目」这类上位概念，记忆挂在它下面。
- 顶部四个 tab：项目 / 工作 / 偏好 / 全局——**切 tab 会过滤画布**，偏好对象只在偏好视图里看得到。
- 点对象 → 右栏能看到它下面挂了几条记忆、和谁有哪种关系、版本历史；可以把记忆挂上来，也可以和另一个对象建关系、合并。
- 偏好对象可以「纠正 AI 的理解」：把「它以为的」改成「你实际想要的」，并选择只在本项目生效还是全局生效。

## 七、AI 会怎么帮你

知微注册了 6 个工具给对话里的 AI：`search` / `recall` / `observe` / `write` / `suggest` / `analyze`。

- 你说「按 XX 任务召回相关记忆」时，AI 会带上项目范围去查，并把命中路径（对象 → 关系 → 记忆）写进调用记录；
- 你贴一段讨论说「观察一下」，AI 会拆成记忆草稿、建议关系，步骤超过三步还会归纳成一个流程对象；
- 所有这些都只写「候选 / 建议」，要不要采纳仍由你点。

## 八、出问题先看这几处

| 症状 | 先检查 |
| --- | --- |
| 面板空白 / 报 404 | 完全退出 DSH 再打开（不是关窗口） |
| 数据看起来没更新 | 顶栏有没有错误提示；设置里看存储路径指向哪个文件 |
| 记忆框点不动 | 先点一下框内空白或虚线轮廓，工具条出现「删除记忆区」即选中成功 |
| 误删了东西 | `Ctrl / Cmd + Z`；再不行用设置里的导入恢复备份 |

## 九、备份建议

设置 → 知微 → 数据：导出整库 JSON。建议在每次大改（批量迁移、导入覆盖、换存储路径）之前导一次。
