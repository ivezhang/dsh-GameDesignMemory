# 知微 · UI 变更与交互清单（V2.4 交付）

面向评审：从"记忆工作台"升级成"知识网络"之后，界面到底变了什么、每个操作怎么用、状态放在哪。逐条对应 `TRACEABILITY.md` 里的需求编号。

## 一、整体骨架

三栏，从左到右：

```
左栏 导航（项目空间 / 视图 / 保存的视图）
中栏 列表 或 关系图画布
右栏 详情（点中记忆或知识对象才出现）
```

- 顶栏：当前视图名 + 条数 + 搜索框 + 「新建记忆」。
- 左栏底部「收起导航」可以把左栏收成图标条，再点展开；默认展开并带文字。
- 右栏在选中项变化时自动切换到对应详情，点空白处收起（关系图里点空白先退出选择，再点一次才收右栏）。

## 二、导航项

| 导航 | 内容 |
| --- | --- |
| 工作台 | 最近改动、待办、统计卡片 |
| 全部记忆 | 全部分组列表 + 筛选 + 批量操作 |
| 待整理 | 缺来源/缺标签/状态为待确认的记忆 |
| 整理中心 | 六类卡片：重复记忆、疑似重复对象、未归类记忆、候选知识对象、缺来源、缺证据 |
| 主题集合 | 集合卡片，点进去看成员 |
| 收藏 / 最近访问 | 常规 |
| 调用记录 | 谁在什么任务下召回了哪些记忆，可点回原记忆 |
| 知识网络 | 四视图：项目 / 工作 / 偏好 / 全局 |
| 关系图 | 画布，可切「全部 / 只看知识对象」 |

项目空间在导航上方：右键改名/删除、拖动排序、`+` 新建，标题栏还有「批量选择」——勾选几个项目后列表上方出现批量条，选目标项目即可「迁移并合并」（记忆 / 对象 / 记忆区 / 集合 / 视图一起迁走，源项目消失）。空间内记忆与知识对象按项目隔离。

## 三、知识网络视图（新增）

- 顶部四个 tab：项目 / 工作 / 偏好 / 全局。**切换 tab 会过滤画布**——偏好对象只在偏好视图可见。
- 画布节点：记忆是单圈实心点，知识对象是双圈、中间一个类型字（项/系/子/概/流/偏/原/法）；超过 6 条记忆的对象显示 `+N` 徽章，点开折叠展开。
- 点节点 → 右栏对象详情：状态、保护级别、置信度、重要程度、被调用次数、来源与证据、正文、步骤（流程对象）、挂着的记忆、关联对象、版本历史。
- 对象详情五个动作：**纠正 AI 的理解**（选"这是在别的项目里"或"缩小范围"）、**合并到另一个对象**（先给影响清单再确认）、**归档**、**从视图隐藏**（眼睛图标，隐藏后画布右上角出现「已隐藏 N / 恢复全部」）、**删除**（二次确认）。
- 新建对象：名字 + 类型 + 所属项目 + 描述 + 标签；类型是流程时可以加步骤，步骤行左侧有拖拽把手，可上下拖动改序，落点行高亮。

## 四、关系

- 建立关系只有一个入口：对象或记忆详情里的「+ 建立关联」。
- 对话框里选目标、选关系类型（28 种按五组分块展示）、写描述。上方实时预览一句自然语言，例如「星云勘测 → 包含 → 传送带」；可勾选"同时建立反向关系"。
- 关系类型分组：层级 / 业务 / 流程 / 偏好与原则 / 知识。每组有组名，选中的类型在预览句里直接出现。
- 关系列表里未确认的（建议中）与已确认的分开展示；可以撤销刚建立的关系。

## 五、列表与批量

- 搜索覆盖：记忆标题/正文/标签、知识对象标题/别名、集合名、项目名，结果分组显示；`Ctrl+K` 聚焦搜索框，`Enter` 打开第一条。
- 筛选：状态、类型、领域、标签、项目、保护级别。
- 批量：勾选后出现批量条——加标签、批量归档、批量改状态、批量移动项目、删除（二次确认）。
- 「全部确认」出现在整理中心的候选对象卡上，一次把候选对象置为已生效。

## 六、快捷键

| 键 | 作用 |
| --- | --- |
| `Ctrl+K` / `Cmd+K` | 聚焦搜索 |
| `Space` + 拖动 | 平移画布 |
| `Shift` + 拖动 | 框选多个节点 |
| `Ctrl` / `Cmd` + 点击 | 多选（累加） |
| `Ctrl+Z` / `Cmd+Z` | 撤销上一次写操作（也可点顶栏的撤销按钮；输入框与弹窗内不拦截） |
| 双击节点 | 聚焦该节点 |
| `Esc` | 关最上层弹窗 → 退选择 → 再 `Esc` 收右栏 |
| `Delete` / `Backspace` | 删除选中（弹确认，不直接删） |

## 七、关系图画布

- 工具条：选择 / 划线（拖到另一节点即建关系）/ 画框（圈出即记忆区）/ 缩放 / 适应 / 收起侧栏 / 保存布局。
- 记忆区：框落库为 `rect`，框内节点自动归属；框可拖动、四角缩放、双击改名、`Delete` 删除（只删框不删节点）；框可嵌套，子框属于父框。
- 老版本画的框（没有 `rect`、只有虚线轮廓）：轮廓带一条透明的加粗命中带，轮廓与中间胶囊都点得中；选中后工具条出现「删除记忆区」「改名」。
- 布局：手动摆过的坐标会保存；切换视图不影响；「恢复自动布局」会清空手动坐标（隐藏状态保留）。
- 点空白处退出选择并关闭右栏；画布背景是点阵，缩放时点阵跟着变。

## 八、设置

在 DSH 设置页里新增「知微」节区：

- **存储**：显示当前数据文件路径，可改到任意绝对路径（切换前自动导出备份）。
- **数据**：导出整库 JSON、导入（合并 / 覆盖两种，覆盖前二次确认）。
- **模型**：若 DSH 注入了模型运行时，可选一个模型供"AI 分析"使用；未注入时此项显示为不可用。

## 九、视觉

- 暗色为主，紫→蓝渐变作为主色；节点按类型着色（项目/系统/概念/流程/偏好各自一色）。
- 选中节点有外发光与加粗描边；多选时整组描边。
- 状态色：草稿灰、待确认黄、待复核橙、已生效绿、已废弃红、已归档淡。
- 所有弹窗淡入 + 轻微上移，遮罩点击可关；`Esc` 一定关得掉最上层。

## 十、与旧版的差异（升级时用户会看到的）

| 之前 | 现在 |
| --- | --- |
| 只有记忆，没有对象 | 记忆之上多一层知识对象，可多对多挂接 |
| 关系只能记忆↔记忆，8 种 | 28 种，两端可以是记忆或对象，带方向与语义 |
| 关系图只是展示 | 可编辑：划线建关系、画框建记忆区、手动布局、保存视图 |
| 没有版本与证据 | 每条记忆、每个对象都有版本历史与来源证据 |
| 没有保护级别 | 三档保护，固有约定默认锁定 |
| 没有整理中心 | 六类待办集中处理，可批量确认 |
| 召回没有记录 | 每次召回落库，可回看命中原因与路径 |
