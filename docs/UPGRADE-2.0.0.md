# 升级到 2.0.0「知微」

## 一句话

插件名改为**知微**，从「手工整理的记忆画布」升级成「AI 辅助的知识工作台」：记忆有类型和状态，关系有语义，主题靠集合归纳，界面是三栏工作台 + 可探索的知识图谱。

## 升级前要知道的

1. **数据会自动迁移，且先备份**。首次启动时旧数据（版本 1/2）就地迁移到版本 3，写回前把原文件复制为 `memories.json.bak`。原文件的标题、正文、标签、要点、时间、置顶、来源都保留，旧分类与旧状态记在 `legacy` 字段里。
2. **内部标识没变**。包名仍是 `@local/design-memory`，数据目录仍是 `%DSH_HOME%/design-memory`，接口仍是 `/design-memory/api`。只有界面上显示的名字变成「知微」。
3. **需要重启 DSH**。host 端（`index.js`）改了数据与接口，必须重启 DSH 进程才会生效；只刷新页面会用新前端请求旧接口。

## 旧概念怎么对应

| 1.x | 2.0 |
| --- | --- |
| 分类 系统/数值/工作流/其他 | 类型 设计规则/数值数据/流程约定/参考案例（`legacy.category` 里留着原值） |
| 状态 已确认 | 已生效 |
| 关联（links） | 参考关系，状态为「用户已确认」 |
| 记忆区（regions） | 主题集合（collections），成员照搬；一条记忆现在可以属于多个集合 |
| 关系网划线 | 关系图「划线」工具 + 关系对话框（必须选关系类型） |
| 关系网画框 | 框选后创建主题集合 / 批量操作；画框本身只是视觉辅助，不再决定归属 |

## 升级后建议做的三件事

1. 打开「待整理」：旧记忆里状态为草稿的那条、以及新记录都会落在这里，确认后改成「已生效」。
2. 在「主题集合」点「AI 建议」：会按领域和标签给出带名称、简介与理由的分组，挑有用的接受。
3. 随便点开一条记忆，用右栏「AI 辅助」跑一次「整理这条」和「推荐关联」，看看建议是否符合你的判断——它只给建议，不会自动改数据。

## 出问题怎么办

- 迁移后条数不对：先看 `%DSH_HOME%/design-memory/memories.json.bak`，那是迁移前的原文件，直接改名回 `memories.json` 再重启即可回到升级前。
- 面板空白 / 接口 404：先确认已经是 2.0.1。2.0.0 有个已知问题：工具注册缺少输出声明，插件启动到一半就失败，路由没挂上，重启后仍然 404。2.0.1 已修复，重新安装/覆盖后重启 DSH 即可。若仍是 404，多半是只刷新了页面没重启 DSH 进程。
- 解析失败：插件会把坏文件改名成 `memories.json.corrupt-<时间戳>` 并重置为空库，不会静默丢数据；把 `.bak` 拷回去即可恢复。

```bash
node tests/render-smoke.mjs     # 前端渲染冒烟
node tests/migrate-live.mjs     # 真实数据结构迁移校验（记忆数、关系数、备份）
node tests/static-audit.mjs     # i18n 与样式类名一致性
node tests/dsh-contract.mjs     # 复刻 DSH 工具/路由注册契约，提前抓启动失败
```
