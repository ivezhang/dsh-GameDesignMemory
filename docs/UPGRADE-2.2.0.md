# 知微 2.2.0 升级说明

本次升级围绕「日常维护不该逼人去划线画框」和「用得久要更顺手」做了一轮体验与能力补齐，数据从 schema v4 平滑升到 v5。

## 一、修好的问题

- **AI 整理关系不能用**：前端有 6 处写请求漏了 `content-type`，服务端按契约返回 415「请求需要 content-type: application/json」。现在统一在请求层补头，AI 整理、查找相似、推荐关系、检查冲突、分析上下游、生成总结全部恢复。
- **项目空间左上角压住**：左栏品牌区、新建按钮、分组标题改为各自占位、不参与压缩，项目名与品牌名超长时省略号截断；顶栏标题先让位，右侧按钮不再被搜索框挤扁。

## 二、项目空间

- 项目行右键：改名、删除（删除时把项目里的记忆与集合迁到第一个项目，记忆本身不丢）。
- 项目行拖动排序：拖动时只更新本地顺序，松手才写库，避免拖拽过程中反复请求。
- 分组标题右侧「+」直接新建项目，弹窗填写名称与说明。

## 三、关系图

- **记忆框**：用「圈区」工具框选一批记忆，落成一个可命名的记忆框。框单独画一层虚线轮廓与标签，和自动集合（实线轮廓）在视觉上分开；记忆框只影响阅读分组，不改变记忆归属。
- **保存布局**：工具栏新增「保存布局」，把当前节点坐标存进数据（`layout.positions`），下次打开关系图按保存的位置还原，再跑一次局部松弛微调。

## 四、设置中心

顶栏齿轮打开设置：

- 存储位置：显示当前路径，可切换到目录或 `.json` 文件；切换前会在旧位置留一份 `.before-switch` 备份，随时切回。
- 导出：把记忆、关系、集合、记忆框、布局导出为 JSON。
- 导入：合并（只补充缺失条目）或覆盖（替换当前库）。
- 整理用的模型：从当前可用的服务商与模型里选一个，并可用开关启用；模型不可用或返回不可解析内容时自动回退本地启发式整理，并在结果里标注「已使用本地整理」。

## 五、数据与兼容

- schema 版本 4 → 5：新增 `frames`（记忆框）与 `layout`（关系图节点位置）。旧库自动迁移，迁移前写 `.bak`，迁移后校验条目数量。
- 设置与模型选择存在 `config.json`（与记忆库同目录），不影响记忆数据本身。

## 六、验证

- `host-test.mjs` 74/74，另含 23 条工作台断言（记忆框、布局、项目排序、导入导出、设置、模型）。
- `render-smoke.mjs` 108/108，含右键菜单、设置弹窗、模型选择、记忆框渲染与保存布局。
- `dsh-contract.mjs` 7/7（工具契约、systemPrompt、路由、payload schema）。
- `migrate-live.mjs` 16/16，`static-audit.mjs` 无错误。

## 七、如何生效

后端（工具、接口、systemPrompt）改动需要**完全重启 DSH**；只改了前端样式时刷新页面即可。重启后用 `GET /design-memory/api` 应看到 `version: 5`，插件面板能正常读写。
