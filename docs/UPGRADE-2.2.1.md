# 知微 2.2.1 升级说明

本次改的是「关系图」，一共两件事：把画布上的控件摆正，让记忆框本身成为可以连线的节点。

## 改了什么

### 1. 修好工具条、计数与导航栏叠在一起

之前画布上的计数（形如 `34 / 8`，节点数与连线数）、临时提示、过滤面板都塞在工具条这个容器里，而计数是绝对定位——结果它压在按钮上面，容器本身又因为没有定位上下文而飘到左栏那边。

现在：

- 工具条只装按钮，按钮多了会换行，不再溢出。
- 计数固定在画布左下，提示固定在右下，过滤面板独立在右侧。
- 画布容器补上 `position: relative`，绝对定位的浮层只在画布里出现，不会越界压到导航栏。

### 2. 记忆框变成可连线的节点

记忆框（「圈区」工具框出来的一组记忆）以前只是画布上的一圈虚线，只能看。现在：

- **框有自己的节点**：虚线胶囊，显示框名与成员数，贴在它框住的那组记忆上方。可以拖动（拖过就会被「保存布局」记住），双击改名。
- **框可以连线**：用「划线」工具从框拖到一条记忆、从一条记忆拖到框、或框连框，都会弹出「建立关系」对话框，选关系类型、写说明、确认即可。关系数据的两端现在允许是框。
- **点框 = 选中成员**：单击框会选中它框住的所有记忆并弹出批量操作条，可以直接改状态、加集合。
- **删框清关系**：删除记忆框时，挂在它身上的关系一并删除，不会留下指向空节点的线。

于是可以这样用：把「星云勘测」相关的一批记忆圈成一个框，再把这个框连到「战斗系统」「活动节奏」等别的节点上——项目结构路径就出来了。

## 数据

- 数据版本仍是 **5**，没有新增字段。`layout.positions` 现在也接受记忆框的 id（框拖过之后保存布局会连框的位置一起存）。
- 旧数据不需要迁移；关系表里出现框 id 时按「节点」解析，前端与导出/导入都按原样保留。

## 验证

- host 测试 74 条全过，其中工作台部分 31 条（新增：框→记忆、记忆→框、框→框、删框清关系、框坐标落盘）。
- 渲染断言 117 条全过（新增：计数不在工具条内、框画成独立节点、点框选中成员、双击开改名、从框拖线开建关系对话框）。
- 静态审计无错误。

## 如何生效

- 前端（画布、工具条）改动：刷新页面即可。
- 服务端（关系两端允许框、删框清关系、布局接受框坐标）：需要**完全重启 DSH**。

## 已知限制

- 框之间暂不支持嵌套（框里再套框）；也还不能整体拖动框来移动成员，框的成员仍由「圈区」或批量操作决定。
- 框的连线会参与自动布局，密集时仍可能互相靠近；可以拖开并「保存布局」固定下来。
