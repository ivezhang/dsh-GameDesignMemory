# 知微 2.3.0 升级说明：记忆区

> 2.3 只做一件事：把「关系图上的框」从「一次性圈选」变成**你自己画出来的一块记忆区**——框里的记忆自动归属它，框里还能套框，检索与召回可以指定在哪块记忆区里找。

## 这次改了什么

### 1. 画框就是建记忆区

选工具条上的「圈区」，在画布上按住拖出一个矩形，松手后给它起个名字。

- 框的位置与大小会存进数据（`frame.rect`），下次打开关系图还在。
- 框用虚线轮廓画出来，像一块区域；名字与成员数标在框的左上角。
- 这是一次「建区域」，不再只是「选中框里的节点」；想只选不建，按住 Shift 画框即可（保持原来的多选行为）。

### 2. 框里的记忆自动归属

- 一条记忆的节点中心落在框里，就属于这块记忆区——不用手动加入。
- 把记忆拖进框、拖出框，归属会自动更新（拖动结束后自动保存布局，宿主按新坐标重算成员）。
- 删掉一条记忆时，它也会自动从框里消失；不会留下空引用。

### 3. 框里可以再画框（嵌套）

- 在已有框里再画一个框，就成了子区域；父框自动包含子框里的记忆。
- 这就是「项目 → 系统 → 模块」的搭法：先圈出一大块项目范围，再在里面对系统分别画小框。
- 删除父框不会删掉子框，只把它们从父框里的成员关系摘掉；记忆本身永远保留。

### 4. 指定在哪块记忆区里找

- 关系图右侧面板新增「记忆区」列表：每块区一行，显示成员数。
- 行上的放大镜 → 「在这块记忆区里找」：中栏切成这块区的清单，直接看这块里有什么。
- 行上的铅笔改名字、垃圾桶删区（记忆保留）。
- AI 侧：`design_memory_search` 与 `design_memory_recall` 都新增了 `frameId` 参数，助手可以只在指定记忆区（含嵌套子框）里检索、召回。

### 5. 顺手修掉的适配问题

右侧详情栏在窄面板里会把内容横向裁掉。现在：

- 详情栏宽度改成 `clamp(272px, 32vw, 372px)`，事实卡改成自适应多列；
- 画布/列表/详情三栏宽度不足 860px 时，详情栏改为浮层，不再把列表挤没；
- 长标签、长关联说明会换行或省略，不再被切一半。

## 数据与兼容

- 数据版本仍是 **5**：只给 `frames` 加了可选的 `rect` 字段，并新增 `frame-sync` 动作；旧数据可直接读，不需要迁移脚本。
- 老版本的「框」没有 `rect` 时仍按成员列表显示（兼容），只是不能自适应框内节点。
- 关系两端仍然允许是框（2.2.1 起），框连框、框连记忆都不受影响。
- 删除记忆区只删区域本身与挂在它身上的关系，**记忆本身不会被删**。

## 怎么生效

- **前端**：刷新页面即可看到新工具条与「记忆区」面板。
- **宿主（host）**：本次宿主侧改了成员自动归属、`frame-sync`、`frameId` 检索/召回——需要**完全重启 DSH** 才会生效。重启后 `GET /design-memory/api` 应能返回 `"version": 5`。

## 关键取舍

- **框的归属按「中心点落在框内」判定**，不按节点半径相交。理由：拖一个节点到框边缘时，用中心点不会有「半个身子算不算」的歧义，读起来更像「这块区域的布局是含义」。
- **成员由位置决定，而不是手动维护列表**。手工成员列表会很快和画布上的框对不上（框挪了、节点挪了），所以只要框有 `rect`，宿主每次存布局后按位置重算；只有当框没有 `rect`（老数据）时才保留手动成员。
- **不做自动布局的自动改框**：重排只改显示位置，不改框坐标与成员；要改归属就拖节点，或重新画框。
- **删除保持「只删容器」语义**：删区、删框都不删记忆。

## 还没做

- 记忆区没有独立的图标/颜色选择器（现在按调色板轮转，可在关系图里后续加）。
- 还没有「把整块记忆区导出成一份文档」的按钮；现在可以导出全库 JSON、或用集合总结。
- 召回只会「只在某块区里找」，还不会自动优先某个区（自动注入仍未接入，见 2.1 的说明）。
