# 知微 2.3.1 升级说明

2.3.0 把「记忆框」升级成了「记忆区」。2.3.1 补上这一步真正要用的几件事：自己画、随手改、以及把被挤扁的顶栏修回来。

## 一、独立的「记忆区」工具

工具条现在是：选择 / 划线 / 记忆区 / 圈选 / 自适应 / 保存布局 / 重排。

- **记忆区**：选它在画布上拖出一个矩形，松手起名，这块区域就是一条 `frame` 数据，位置与大小（`frame.rect`）一起存进仓库。
- **圈选**：只做选择——框完松手直接得到一组选中节点（批量条：加入集合 / 改状态 / 清除），不会再顺手建一块区。两者分开，手滑也不会多出一块空区。

## 二、画好的记忆区可以改

- **拖动整块**：按住框体拖动，框和框里的记忆一起换位置；松手后自动保存布局，宿主按新位置重算成员。
- **四角缩放**：选中框后四个角出现把手，拖动手柄改大小，松手同样重算成员。
- **改名**：双击框顶边的名字标签。
- **删除**：选中框按 Delete / Backspace；或者侧边面板「记忆区」列表里的删除按钮。删框只删区域，里面的记忆与它们的正文都保留。
- **嵌套**：框里可以再画框，父框自动包含子框里的记忆；检索与召回按嵌套关系递归展开。

## 三、框是矩形节点

框的标题贴在框的上边线（名字 + 成员数），框本体可以像记忆节点一样被「划线」连到别的记忆或别的框，也可以被拖动。这样一条完整的结构路径就是「框（系统）→ 框（模块）→ 记忆（规则/数值/决策）」。

## 四、顶栏不再被挤成竖排

中栏变窄时（例如左右两栏都展开、窗口又不宽），原先标题会被压成逐字竖排、搜索框把按钮挤到画布上。现在：

- 标题与副标题单行显示，放不下用省略号，不换字；
- 标题行允许换行，搜索框自己让位到第二行；
- 顶栏带底色与层叠上下文，画布点阵不会从顶栏透出来。

## 五、数据与兼容

- 数据版本仍是 **5**，没有新字段：2.3.0 写入的 `frame.rect` 直接继续用。
- `frame-save` 收到新 `rect` 时会按新位置重算成员；旧数据没有 rect 的框仍按显式成员列表工作。
- 升级前会自动留一份 `.bak`，迁移与保存都走「先备份、再临时文件、最后原子改名」。
