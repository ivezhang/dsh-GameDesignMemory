# 知微 2.3.2 升级说明

这一版只修两块真问题：**详情栏里内容互相压住**（关系列表错位），以及 **2.3.0 之前画的记忆框点不中、删不掉**。

## 一、详情栏错位（截图里的「采纳/忽略」飘在改动记录上）

**根因**：详情栏「关联记忆」的列表容器误用了图例短线类 `.zw-relLine`——那是给 14px 宽、0 高的分隔线用的样式。把整组关系塞进这个容器后，行高被压成 0、宽度锁死在 14px，内容全部溢出，于是关系行上的「采纳 / 忽略」按钮飘到了下面的「改动记录」上，AI 辅助的提示文字也压到了按钮上。

**修法**：新增独立容器 `.zw-relList`（纵向排列、`min-width: 0`），关系行恢复正常流式布局；同时给 `.zw-blockHead` 加换行、提示条限宽、关系行允许换行。

## 二、窄面板（≤620px）加固

详情栏在很窄的窗口下占满宽度时：

- 事实卡固定两列，不再挤成一条；
- 标题、辅助按钮字号收紧，`AI 辅助` 的动作胶囊换行排布；
- 块标题与右侧提示可以换行，不再互相覆盖。

## 三、老记忆框可以操作了

2.3.0 之前创建的框只有成员列表（`memberIds`）、没有 `rect`，画布上只有一层虚线轮廓，点不中，所以「没法删改」。

现在：

- **点** 虚线轮廓 → 选中该框的全部成员（出现批量操作条）；
- **双击** 轮廓 → 重命名；
- 选中后按 **Delete / Backspace** → 删除该记忆区（记忆本身保留）；
- 侧栏「记忆区」列表里的改名、删除按钮照旧可用，也是给老框兜底的入口。

新画的框（有 `rect` 的）行为不变：拖动整块、四角缩放、框顶双击改名、Delete 删除。
