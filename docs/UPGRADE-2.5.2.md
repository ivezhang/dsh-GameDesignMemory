# 知微 2.5.2 升级说明

## 改了什么

1. **知识对象的版本历史**：对象改名、改描述、改类型、改状态都会追加一版，记下时间、变更类型（新建 / 修改 / 改名 / 改类型 / 改状态 / 归档 / 回滚）与原因（如果填写了「这次修改的原因」）。
2. **可以回滚**：对象详情里「历史版本」列出每一版，除当前版外都能「回到这一版」。回滚会恢复标题、描述与类型，并把这次回滚也记成一版——历史只增不减。
3. **修了一个更新 bug**：之前只改描述或状态时，更新会报「知识对象需要一个名字」，因为更新路径也要求必填名字。现在更新缺省沿用原名字。

## 数据安全

- 数据版本仍是 6。旧对象没有 versions 字段时，载入时自动补一条「第 1 版（create）」，不会丢内容。
- 版本最多保留 40 条（与记忆版本同样的上限），超出后丢最旧的版本。
- 回滚只改标题 / 描述 / 类型，不改状态、关系、关联记忆与成员。

## 如何生效

- 后端：需要完全退出并重启 DSH（保存逻辑与 normalize 都改了）。
- 前端：刷新页面即可看到「历史版本」区块。

- 版本上限 40，超出丢最旧。
