# 知微 2.5.3 升级说明

## 这一版在补什么

三处都是 V2.4 交互规范里点名的细节，这次补齐：

1. **关系类型分组**：新建关系（记忆与记忆、对象与对象、对象与记忆）时，28 种关系类型按五个语义组显示——
   层级（包含 / 属于 / 是…的一部分）、业务（出现在 / 使用 / 掉落 / 需要 / 由…制作 / 影响 / 依赖 / 与…平衡）、
   流程（遵循 / 先于 / 下一步 / 触发 / 产出 / 是…的例外）、偏好与原则（偏好 / 避免 / 适用于 / 指导 / 约束）、
   知识（关联于 / 来源于 / 参考 / 冲突 / 替代 / 细化）。
2. **整理中心批量确认**：候选知识对象多于一条时出现「全部确认」，按同一处理方式批量启用；不把不同性质的建议混进同一个批量按钮。
3. **展开全部**：关系图工具条新增按钮，一键收起所有折叠状态；节点超过 120 个时给一句提示，建议改用记忆区或筛选收窄范围。

## 数据与生效

- 数据版本仍是 6，**没有后端改动**：刷新页面即可生效，不需要重启 DSH。
- 没有删除或改写任何已有数据。
