# 知微 2.5.4 升级说明

## 这一版做了什么

1. **「从视图隐藏」**（V2.4 规范 5.16 里与「移除关联 / 归档 / 删除」并列的那一种）
   - 知识对象详情头部新增眼睛按钮：隐藏后它从画布上消失，但数据、关系、所属记忆、所属记忆区全都不变；
   - 关系图右侧过滤面板显示「已隐藏 N」，可一键「恢复全部隐藏节点」；
   - 这是纯视觉状态，存在布局里，和业务归属完全分开。

2. **修两个真 bug**
   - 布局接口原来只接受记忆与记忆区 id，知识对象的坐标根本存不进去（拖动后刷新就回去了）；清理逻辑还会把知识对象从布局里剔除。现在画布上的三类节点统一处理。
   - 只改隐藏状态时，原来的保存会用一个空 positions 覆盖整个布局，把大家辛苦摆的位置洗掉。现在不带 positions 的保存会沿用已有坐标。

3. 记忆区的成员归属也跟着扩展：框里可以框住知识对象，拖进去就算属于这个区。

## 数据与生效

- 数据版本仍是 6，layout 只是多存了一个 hidden 数组；旧数据载入时自动补空数组。
- 后端有改动（布局接口），需要完全重启 DSH；重启后前端刷新即可。
