# 升级到 2.5.7

## 改了什么

### 1. 批量操作补齐

多选之后，批量条从「加入集合 / 设为有效 / 清除」扩成：

| 按钮 | 行为 |
| --- | --- |
| 加入集合 | 勾选集合，可当场新建 |
| 设为有效 | 批量改成「已生效」 |
| 归档 | 批量改成「已归档」（不删内容） |
| 加标签 | 输入一个标签，选中的记忆都加上；已有同名标签不重复加，其它标签不动 |
| 删除 | 二次确认后删除；删掉的关系与内容可从提示里的「撤销」恢复 |

后端 entry-bulk 新增 addTag / removeTag 两种 op，标签为空会直接 400 拒绝。

### 2. 搜索覆盖集合与项目

以前搜索只搜记忆和知识对象。现在一次搜四类，结果分组展示：

- 知识对象：点击切到知识网络并打开详情；
- 主题集合：点击直达集合页；
- 项目：点击按该项目过滤列表；
- 记忆：下方列表照旧。

这样「我记得有个集合叫…」「那个项目叫…」这两种最模糊的回忆也能直接找到。
