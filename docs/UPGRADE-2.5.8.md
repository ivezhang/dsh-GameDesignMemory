# 升级到 2.5.8

## 改了什么

### 1. 修掉跨项目误召回

调用召回时传了 projectId，本意是「只在这个项目里找」。原来的实现只是把别的项目的记忆排到最后（tier 4），并没有排除——只要任务词命中，它们仍然会出现在结果里。

现在：

- 传 projectId：只有本项目的记忆和全局记忆（scope=global）参与，别的项目即使词面命中也不返回；知识对象同样按项目收口，全局对象仍参与。
- 不传 projectId：行为不变，仍然全库参与并按四层优先级排序。

host 测试新增「recall does not leak memories from other projects」，钉住「他项目不返回、全局仍返回」两件事。

### 2. 新增数据层验收脚本

tests/acceptance.mjs 会把线上库复制一份到临时目录（不碰原文件），在真实数据上跑 7 项核心验收：

| 编号 | 验收项 |
| --- | --- |
| A1 | 原有记忆都有版本历史与来源证据 |
| A2 | 固有约定不会被静默改写，只有用户明确修改才生效 |
| A3 | 指定项目召回不会带出其他项目的记忆 |
| A4 | 每条关系都有来源与置信度，两端都能解析 |
| A5 | 对象重复率可控（疑似重复对为 0） |
| A6 | 迁移与读写没有静默丢数据 |
| A7 | 宿主契约完整（6 个工具 + 路由） |

结果写进 ACCEPTANCE.md，当前 7/7。它只覆盖数据与接口层，真人鼠标走查仍按 WALKTHROUGH.md 做。
