# 升级到 2.5.9

## 改了什么

### 1. 知识网络页也能批量操作

批量条原来按页面读不同的选区：关系图页读画布选区，知识网络页读列表勾选——而知识页没有列表，所以永远是空的。现在两页共用画布选区，Ctrl/Cmd 点两个对象就能看到「加入集合 / 设置状态 / 归档 / 加标签 / 删除」。

### 2. 清掉一行调试日志

关系图 Delete 分支里遗留的 console.log 已删除，控制台不再刷选区信息。

### 3. 补了 11 条交互断言

| 断言 | 对应需求 |
| --- | --- |
| Esc 关闭最上层弹窗 | 5.2 / 11.17 |
| 关弹窗不影响页面与数据 | 11.17 |
| Esc 取消画布选择 | 5.2 |
| 双击对象进入局部聚焦 | 5.2 |
| Space + 拖动平移画布 | 5.2 / 11.3 |
| 平移不会创建记忆区 | 5.2 / 11.3 |
| 平移不弹任何对话框 | 5.2 |

| 超长名称仍能保存 | 11.18 |
| 标题按 120 字上限截断 | 11.18 |
| 知识页批量条与关系图一致 | 5.3 |
