# 升级到 2.6.0

## 改了什么

流程对象（workflow）的步骤原来只能靠「上移 / 下移」两个按钮调整，V2.4 需求第六节要求「改序用明显把手」。这一版补上了：

- 每个步骤左侧有拖拽把手（悬停变手型），按住拖到目标行即可换序。
- 拖动时目标行有虚线落位提示，被拖的行半透明。
- 松手立即生效，保存时按新顺序写入；上移 / 下移按钮继续保留，键盘用户也能用。

## 数据

数据版本仍是 6，流程步骤结构没变（仍是 id / title / note 数组）。

## 验证

- 渲染测试 226 checks（新增 12 条：把手数量、拖拽换序、其余步骤相对顺序、保存载荷顺序）。
- host 96 tests + WORKSPACE 55 checks、契约 8、迁移 16、数据层验收 7/7、静态审计干净。

## 如何生效

前端改动，刷新页面即可；不需要重启 DSH。
