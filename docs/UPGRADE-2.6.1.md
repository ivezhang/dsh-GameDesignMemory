# 2.6.1 升级说明：场景 A 端到端演练

## 这一版做了什么

没有改产品代码，补的是「跨系统项目关系」这条业务场景的端到端证据。

新增 tests/scenario-a.mjs：在一个临时 DSH_HOME 的空库里，用真实接口从零搭一套结构——

1. 系统「副本系统」→ contains → 概念「哥布林洞窟」
2. 洞窟 → contains → 怪物「哥布林」→ contains → 变种「哥布林弓箭手」
3. 哥布林 → drops → 材料「铁矿石」；装备「铁剑」→ crafted_from → 铁矿石
4. 一条记忆「哥布林洞窟掉落规则」通过 node-link-memory 挂到哥布林上
5. 按任务「调整哥布林洞窟掉落」召回，检查命中对象与召回路径

## 验证结果

6 / 6 通过：结构落库与父级、关系类型与方向且没有存成重复反向、记忆双向可查、召回先命中对象并带出记忆与路径、没有凭空造对象、没有悬空关系。报告见 docs/SCENARIO-A.md。

## 如何看到

在插件目录跑 node tests/scenario-a.mjs，会重新生成 docs/SCENARIO-A.md。它不读也不写线上库。
