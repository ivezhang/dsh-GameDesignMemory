# 2.6.2 升级说明：观察时自动归纳工作流程

## 这一版做了什么

以前你贴一段操作步骤进「观察」，系统只会把它拆成记忆；现在它会先看这段文字有没有先后关系，有就顺手给一个流程对象。

判定条件很保守：

- 文字里出现「先 / 首先 / 第一步 / 然后 / 接着 / 随后 / 之后 / 最后 / 再」，或者以「1. 2. 3.」编号；
- 至少凑出三步；
- 已经存在同名流程、或步骤重合两个以上的流程对象时不再新建。

新对象的状态是「候选」：它会出现在整理中心，你确认后才变成正式流程；确认后可以在对象详情里继续加步骤、拖动排序、挂记忆。

## 验证

host 测试新增一条：四步文字 → 建出 workflow 候选（步骤落库、状态候选）→ 同样的文字再观察一次不重复建 → 整理中心列得出来。整套 97 tests 通过，渲染 226 checks、契约 8、迁移 16、数据层验收 7/7、场景 A 6/6、静态审计干净。

## 仍然没做到的

- 跨多次对话把同一条流程**逐步补全**：现在第二次观察会判断「已有相似流程」就跳过，不会把新步骤补进去。要补得手改，或等后面把「步骤补充」做成更新提案。
- 流程的「触发条件 / 输入输出」仍要手填，观察只抽得出标题与步骤。
