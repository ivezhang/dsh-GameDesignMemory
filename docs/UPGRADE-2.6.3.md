# 2.6.3 升级说明：偏好纠正补上交互断言

## 这一版做了什么

没有改产品代码，补的是「偏好被 AI 误判时怎么纠正」这条交互的证据。渲染测试现在会完整走一遍：

1. 左栏切到「知识网络」，再切到「偏好」视图；
2. 点中一个偏好对象，右侧详情里出现「纠正 AI 的理解」；
3. 点编辑图标打开纠正对话框（文案解释了三种选择）；
4. 选「缩小范围」，保存；
5. 断言这次保存发的是 node-save、带 scope=project，并把纠正内容记成对象的一条属性。

## 验证
