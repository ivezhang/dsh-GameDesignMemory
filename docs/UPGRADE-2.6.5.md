# 2.6.5 升级说明：同一条流程跨对话逐步补全

## 之前的情况

2.6.2 能在观察对话时把「先…然后…接着…」归纳成一个流程对象候选，但只做第一次：再说一遍会被判成「已有相似流程」直接跳过，新补的步骤就丢了。

## 现在

- 第二次观察时，如果这次识别出的步骤里有一部分是新的，就并进同一个流程对象：原有步骤顺序与 id 保留，新步骤追加在后面，整个对象仍然只有一个。
- 合并会写进对象版本历史（版本快照现在包含步骤清单），在详情里能回滚。
- 目标对象若是固有约定（protected），不静默改，返回里说明「需要你手动补步骤」。
