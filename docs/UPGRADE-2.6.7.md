# 知微 2.6.7 升级说明

## 这版解决什么

整理中心里有个「疑似重复」的清单。之前它只看两个对象的标题和描述，所以两条流程如果标题起得不一样、但步骤几乎是同一件事，它会当成两个不同的对象，永远发现不了。

2.6.7 把流程步骤也算进判重语料：

- 对象语料 = 标题 + 描述 + 所有步骤标题；
- 两个流程对象共享 ≥2 个同名步骤 → 判为疑似重复；
- 理由会写明「都是流程对象，有 N 个步骤同名」，你一眼能看出为什么被挑出来。

## 你会看到的变化

整理中心 →「疑似重复的对象」里，措辞不同但步骤重合的两条流程会出现在一起，点进去可以合并。

## 不受影响的部分

- 数据版本仍是 6，不需要迁移数据。
- 记忆层面的重复判断（整理中心的「疑似重复」记忆）逻辑没变，只改了知识对象这一侧。
- 统计与召回不受影响。

## 已知限制

步骤判重是**字符串完全相同**才算同名。同一个动作换了写法（「打开配置表」vs「把配置表打开」）仍然认不出来，需要人工合并——这条在 docs/OPEN-ITEMS.md 里。
