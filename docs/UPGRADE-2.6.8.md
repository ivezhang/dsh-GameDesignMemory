# 知微 2.6.8 升级说明

## 这版修了一个会丢数据的 bug

整库导出（设置 → 导出）导出的 JSON 里，**一直没有知识对象**。导入也只处理记忆、关系、集合、记忆框，从来不写回对象。结果是：你在 2.4 之后建的项目 / 系统 / 流程 / 偏好，导出再导入就全没了——对象本身、它的版本历史、它和记忆的挂接关系，一起消失。

2.6.8 补上两处：

- 导出：`data.nodes` 带上全部知识对象；
- 导入：`merge` 按 id 合并、`replace` 整体替换，都会写回对象，`imported.nodes` 里能看到带了几个。

## 新增：只导出一个项目

项目空间里右键任一个项目 →「导出这个项目」，会导出只属于这个项目的一份 JSON：

- 对象与记忆：该项目名下的全部内容；
- 关系：两端都在这份导出范围内的关系；
- 集合 / 记忆框：属于这个项目、或包含这些节点的那部分；
- 画布：这些节点的坐标与隐藏状态。

文件名形如 `zhiwei-N2-猎星者-20261126.json`，可以直接当项目备份或交接材料。

## 会受影响的地方

- 之前用整库导出做过的备份，里面没有对象层。如果你有旧备份，导入后对象需要重建；从现在起的新备份是完整的。
- 导入仍是整库 merge / replace，还不支持「只导入某几个集合」（见 docs/OPEN-ITEMS.md 第 7 条）。
- 数据版本仍是 6，不需要迁移。
