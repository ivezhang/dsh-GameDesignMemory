# 知微 2.8.0 升级说明

这一版只做三件事：把「记忆区」变成真正的容器、把关系图铺满窗口、让 AI 能一键整理。

## 一、记忆区终于是「一个整体」了

之前你觉得框没用，是四个问题叠在一起：

1. **拖框只搬框，不搬记忆。** 框的坐标（`rect`）变了，框里记忆的坐标没变，松手后服务端按坐标重算归属，成员就掉光了。
   现在拖框时成员的坐标跟着一起平移，松手后连同成员一起保存（`frame-save` 带上 `memberIds`），并且马上落一次布局。
2. **框和记忆各自飘。** 有 `rect` 的框还会额外画一颗「记忆区胶囊」，两者位置分开维护，看起来就像两个东西。
   现在有 `rect` 的框不再画胶囊：框本身既是容器，也是唯一的存在。
3. **退出再进来就散了。** 以前进入关系图每次都会重新跑一遍力导向布局，节点被挪到框外，框里按坐标一算就空了。
   现在已有坐标原样沿用，只在缺坐标时才补算；窗口尺寸变化时也不会打乱位置。
4. **新建的框立刻变空。** 服务端在收到 `frame-save` 时不管客户端传没传成员，一律按坐标重算。
   现在客户端明确提交成员就以提交的为准，只有没提交时才按位置推断。

顺带修了一个拖动的时序问题：拖得快时，指针抬起读到的是上一帧的草稿矩形，框会「弹回去」；现在草稿另存一份 ref，落库用的始终是最后拖到的位置。

## 二、关系图按真实窗口铺开

`适应窗口`（以及首次进入关系图）之前用的是首帧兜底的 900×560，容器比这个窄时图会画到可视区外，看起来「显示不全」。
现在按画布容器的真实尺寸计算，并在窗口尺寸变化时自动重新适应一次；你手动缩放或平移到别处后，不会被强行拽回来。

## 三、整理中心：AI 一键整理

整理中心工具条新增「**AI 一键整理**」。点它先出一份预览（只读，不改任何东西），告诉你会合并几条重复记忆、确认几条关系；确认后才真正执行：

- **合并高度重复的记忆**：同类型、共同标签 ≥ 2 且主题词高度重合的，留下更早创建的那条，后来的并进去（保留关系、集合与版本历史）。
- **确认把握很大的关系**：置信度 ≥ 0.9 的建议关系直接转为已生效。
- **受保护的记忆一律跳过**：固有约定不会被合并。
- 整次整理算作一步操作，可以用 Ctrl / Cmd + Z 或顶栏「撤销」退回。

对话里的 AI 也能用：工具新增 `tidy-apply`，`dryRun` 默认 `true`，先预览再执行。
