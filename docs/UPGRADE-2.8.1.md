# 升级说明 2.8.1 — 知识网络画布铺满，界面不再错位

升级方式：关闭 DSH 后覆盖插件目录里的 `index.js`、`client.js`、`package.json`、`README.md` 与 `docs/`，重新打开 DSH。数据版本仍是 6，不需要迁移。

## 一、修了什么

| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 知识网络画布只有一条窄带，节点全挤在左上角 | 知识视图给画布套的容器不是 flex 容器，画布里的 stage 拿不到高度，塌成内容高度 | 容器改成纵向 flex（`display:flex; flexDirection:column`），画布铺满 |
| 侧栏收起、切换 tab 后图不居中 | 只在 window resize 时量尺寸 | 换成 ResizeObserver 监听容器，并加 rAF 兜底重新适应 |
| 容器刚挂载、尺寸还是 0 时图被压到角落 | 按 0 尺寸算过一次适应 | 视口小于 120×120 时跳过适应 |
| 「新建知识对象」被挤到画布上方 | 顶栏一行放不下 | 标签换行、副标题省略、按钮回位 |
| 副标题显示「34 条」但知识对象只有 2 个 | 复用了记忆条数 | 知识视图显示当前视图的对象数 |
