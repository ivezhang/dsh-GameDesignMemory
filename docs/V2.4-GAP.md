# 知微 V2.4 差距清单（需求 vs 现状）

> 生成时间：2026-11-26。基线：本地 2.4.0（已部署未推送）。本文先逐条对照需求与现有实现，标出「已有 / 部分 / 缺失」，作为后续 P0–P4 的施工依据。

## 0. 现有实现速览

- 数据：`memories.json` 单文件，`version 5`。`entries`（Memory，13 种 type）、`relations`（8 种关系，Memory↔Memory）、`collections`、`frames`（记忆区，含 rect）、`layout`（节点坐标）、`projects`、`views`、`versions`/`evidence`/`proposals`/`recalls`。
- 宿主：`index.js` 约 4.8k 行，6 个工具（search / write / suggest / analyze / observe / recall），HTTP `/design-memory/api`，`ctx.llm` 已接通模型。
- 前端：`client.js` 约 12k 行，三栏工作台 + 列表/总览/集合/整理中心/调用记录/关系图（Memory 节点 + 记忆区框 + 集合 hull）。
- 测试：host 76 tests + 50 checks、render-smoke 137 checks、dsh-contract 7、migrate-live 16、static-audit clean。

## 2. 施工顺序（与需求第十四章一致）

1. **P0**：Node 模型 + 关系跨类型 + 迁移 v6 + 旧功能兼容（host 先行，测试兜底）。
2. **P1**：手势状态机、关系弹窗、Node 建/编、关联记忆、搜索定位、反馈与撤销。
3. **P2**：知识网络四视图、展开折叠、Node 详情特化（workflow/preference）。
4. **P3**：observe 产出 node 候选、node-merge、整理中心新增卡。
5. **P4**：recall 走 node → 关系路径 → memory，记录路径。
6. 测试与交付文档（架构/模型/迁移/UI/交互清单/测试结果/走查/未完成）。
